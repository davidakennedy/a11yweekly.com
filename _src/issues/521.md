## Featured: The web needs interactive lists

"Developers and designers will always create new innovative ways to be weird and inaccessible in their UI (intense side-eye at stuffing tabs and tables into comboboxes), and spec authors will always struggle to decide how far to support the chaos. However, every once in a while developers and designers create a perfectly normal, understandable, and theoretically accessible UI pattern that for whatever reason is not supported on the web. One of those patterns is an interactive list."

Read more of [The web needs interactive lists](https://sarahmhigley.com/writing/interactive-lists/).
